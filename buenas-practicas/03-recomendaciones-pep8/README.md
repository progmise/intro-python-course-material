# Buenas Prácticas 03: Otras Recomendaciones de PEP 8

## 📌 Descripción
Ejemplos correctos e incorrectos de [PEP 8](https://peps.python.org/pep-0008/) sobre:

- Espacios alrededor de operadores binarios y prioridades.
- Espaciado en anotaciones de tipo (`input: str`, `-> int`).
- `=` en argumentos por palabra clave y valores por defecto.
- Declaraciones compuestas (varias sentencias en una línea): por qué evitarlas.

El archivo es ejecutable: los ejemplos "incorrectos" también corren, pero muestran el estilo a evitar.

## 🧠 Conceptos Aplicados
- Convenciones de espaciado de PEP 8.
- Type hints en firmas de funciones.
- Legibilidad: una sentencia por línea.

## 🚀 Cómo ejecutar
```bash
python main.py
```
