# Buenas Prácticas 01: Indentación según PEP 8

## 📌 Descripción
Ejemplos comentados de indentación correcta e incorrecta según [PEP 8](https://peps.python.org/pep-0008/):

- 4 espacios por nivel de indentación.
- Alineación de argumentos en llamadas y firmas multilínea.
- Indentación en estructuras `if` multilínea.
- Ubicación del paréntesis/corchete/llave de cierre.

## 🧠 Conceptos Aplicados
- Reglas de indentación de PEP 8.
- Continuación de líneas dentro de delimitadores.
- Distinción visual entre argumentos y cuerpo de función.

## 🚀 Cómo ejecutar
```bash
python main.py
```
