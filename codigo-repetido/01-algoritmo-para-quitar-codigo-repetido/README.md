# Código Repetido 01: Algoritmo para Quitar Código Repetido

## 📌 Descripción
Procedimiento visto en clase para eliminar duplicación de código mediante **abstracción**:

1. **Copiar** lo repetido a "otro lado" (una nueva función).
2. **Parametrizar** lo que cambia entre cada repetición.
3. **Nombrar** la abstracción (darle un nombre declarativo a la función).
4. **Reemplazar** lo repetido por llamadas a la nueva abstracción.

> **Abstracción**: proceso por el cual se separa o aísla alguna o algunas cualidades de un objeto o de una acción sobre el mismo.

## 🧠 Conceptos Aplicados
- Detección de código duplicado (DRY: *Don't Repeat Yourself*).
- Extracción de funciones y parametrización de las diferencias.
- Nomenclatura declarativa de abstracciones.
