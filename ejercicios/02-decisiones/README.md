# Ejercicio 02: Estructuras de Decisión

## 📌 Enunciado
Solicitar al usuario un número entero e informar si es **positivo**, **negativo** o **cero**.

El archivo contiene cuatro variantes comentadas para comparar el comportamiento de `if/else` frente a `if` consecutivos, y el efecto de mutar la variable dentro de una rama. La versión activa usa `if/elif/else`.

## 🧠 Conceptos Aplicados
- Estructuras condicionales: `if`, `elif`, `else`.
- Comparaciones: `>`, `<`, `==`.
- Mutación de variables dentro de una rama y su impacto en condiciones posteriores.

## 📥 Ejemplo de Entrada / Salida
- **Entrada**: `5` → **Salida**: `Número positivo`
- **Entrada**: `0` → **Salida**: `Es igual a 0`
- **Entrada**: `-3` → **Salida**: `Número negativo`

## 🚀 Cómo ejecutar
```bash
python main.py
```

Para probar las variantes anteriores, descomentar el bloque correspondiente y comentar la solución activa.
