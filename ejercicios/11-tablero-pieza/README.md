# Ejercicio 11: Superponer una Pieza en un Tablero

## 📌 Enunciado
Dado un tablero de 4x4 (lista de listas) y una "pieza" modelada como lista de coordenadas `[x, y]`, marcar con `"X"` las posiciones que ocupa la pieza y mostrar el tablero resultante.

## 🧠 Conceptos Aplicados
- Matrices como listas de listas.
- Triple bucle: filas × columnas × coordenadas de la pieza.
- Desempaquetado `for x, y in pieza`.
- Función `main()` como punto de entrada.

## 📥 Ejemplo de Entrada / Salida
- No requiere entrada.
  - **Salida**: la primera columna del tablero queda marcada con `"X"` en las filas 0, 1 y 2.

## 🚀 Cómo ejecutar
```bash
python main.py
```
