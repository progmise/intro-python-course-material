# Ejercicio 01: Operaciones Básicas y Formatos de Impresión

## 📌 Enunciado
Implementar un programa que solicite al usuario el ingreso de **dos números enteros** y muestre por consola la **suma, resta, multiplicación y división** de ambos.

El archivo además muestra 5 variantes para formatear cadenas en `print()`, culminando con los *f-strings*, que son la forma recomendada.

## 🧠 Conceptos Aplicados
- Lectura de datos por consola (`input()`) y conversión a entero (`int()`).
- Operadores aritméticos: `+`, `-`, `*`, `/`.
- Formateo de cadenas: `str.format()`, múltiples argumentos de `print()`, concatenación, operador `%` y *f-strings*.

## 📥 Ejemplo de Entrada / Salida
- **Entrada**: `10` y `2`
  - **Salida**: `La suma de los números 10 y 2 es 12` (y análogamente para resta, multiplicación y división)

## 🚀 Cómo ejecutar
```bash
python main.py
```
