# Ejercicio 10: Conjuntos y Generación de Informes

## 📌 Enunciado
Dada una lista de notas de alumnos (cada registro es un diccionario con `nombre`, `nota` y `materia`), calcular el **promedio de notas por alumno** y mostrarlo por consola.

Se usa un **conjunto** (`set`) para obtener los nombres únicos antes de agregar las notas.

## 🧠 Conceptos Aplicados
- Conjuntos (`set`) para eliminar duplicados.
- Lista de diccionarios como estructura de datos.
- Contadores y acumuladores para calcular promedios.
- Generación de una lista de informes (diccionarios) a partir de datos crudos.

## 📥 Ejemplo de Entrada / Salida
- No requiere entrada. Con los datos incluidos:
  - **Salida**: `El alumno Leonel tiene un promedio de 5.00` / `El alumno Nicolas tiene un promedio de 8.50`

## 🚀 Cómo ejecutar
```bash
python main.py
```
