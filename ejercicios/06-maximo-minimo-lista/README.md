# Ejercicio 06: Máximo y Mínimo de una Lista

## 📌 Enunciado
Dada una lista de números enteros, encontrar el **máximo** y el **mínimo** y mostrarlos por consola.

Se presentan tres soluciones: funciones built-in `max()`/`min()`, recorrido manual en un solo bucle, y una versión modularizada con funciones.

## 🧠 Conceptos Aplicados
- Funciones built-in `max()` y `min()`.
- Recorrido de listas con `for`, comparaciones y actualización de extremos.
- Definición de funciones con parámetros, valor de retorno y type hints.

## 📥 Ejemplo de Entrada / Salida
- Para la lista `[1, 4, 2, 3, 99, 100]`:
  - **Salida**: `El número máximo de la lista de números es: 100` / `El número mínimo de la lista de números es: 1`
