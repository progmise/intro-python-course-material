# Ejercicio 05: Palabras Intercaladas

## 📌 Enunciado
Una cadena contiene **dos palabras intercaladas**: los caracteres en posiciones pares pertenecen a la primera palabra y los de posiciones impares a la segunda. Separar ambas palabras y mostrarlas por consola.

Se presentan 3 soluciones: slicing con paso, dos bucles `range()` con paso 2, y un único bucle que toma los caracteres de a pares.

## 🧠 Conceptos Aplicados
- Slicing de cadenas con paso (`[inicio::paso]`).
- `range()` con paso para recorrer posiciones pares e impares.
- Construcción de cadenas por concatenación en un bucle.

## 📥 Ejemplo de Entrada / Salida
- **Entrada**: `"hcohlaau"`
  - **Salida**: `Primer palabra: hola` / `Segunda palabra: chau`

## 🚀 Cómo ejecutar
```bash
python main.py
```
