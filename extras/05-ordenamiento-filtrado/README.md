# Extra 05: Lambdas, Ordenamiento y Filtrado

## 📌 Descripción
Archivo de referencia con ejemplos de:

- **Lambdas**: funciones anónimas de una sola expresión.
- **Ordenamiento**: `.sort()` (in-place) vs. `sorted()` (devuelve lista nueva), sobre estructuras simples y complejas, con el parámetro `key` como criterio y `reverse=True` para orden descendente.
- **Filtrado**: `filter()` con lambda para quedarse con los elementos que cumplen una condición.

Los ejemplos están comentados: descomentar de a un bloque para ejecutarlo y comparar resultados.

## 🧠 Conceptos Aplicados
- `lambda parametros: expresion`.
- `lista.sort(key=..., reverse=...)` vs. `sorted(iterable, key=..., reverse=...)`.
- `filter(funcion, iterable)` y materialización con `list()`.
- Criterios de ordenamiento sobre diccionarios (`barco['clave']`) y listas (`nota[indice]`).
